ROS1 到 ROS2 迁移作业报告（ego-planner）

一、原始工程简介及选择理由

ego-planner 是浙江大学 FAST 实验室开源的四旋翼无人机在线轨迹规划框架，由十几个 ROS 包组成，分为规划器（plan_env、path_searching、bspline_opt、ego_planner 等）和仿真器（uav_simulator 下的 so3_control、so3_quadrotor_simulator、mockamap、map_generator、quadrotor_msgs、pose_utils 等）。原始工程基于 ROS1，用 catkin 构建。

选择它作为迁移对象，是因为它包数量多、规模适中，几乎覆盖了 ROS 开发的所有常用 API：发布者、订阅者、参数、自定义消息、tf 坐标变换、点云（PCL）、定时器，以及 catkin 构建系统。迁移一遍就能把 ROS1 到 ROS2 的所有典型改动都练到，适合作为迁移学习的完整案例。

二、迁移步骤及代码差异

迁移按依赖关系从底层到上层进行：先改消息包和工具库（quadrotor_msgs、pose_utils、multi_map_server），再改各功能节点。主要改动如下。

1. 构建系统（每个包都要改 package.xml 和 CMakeLists.txt）

-  <buildtool_depend>catkin</buildtool_depend>
-  <build_depend>roscpp</build_depend>
-  <run_depend>roscpp</run_depend>
+  <buildtool_depend>ament_cmake</buildtool_depend>
+  <depend>rclcpp</depend>

CMakeLists.txt 里 find_package(catkin COMPONENTS ...) 改为逐个 find_package(ament_cmake、rclcpp 等)，链接改用 ament_target_dependencies，并补上 install(TARGETS ...) 和结尾的 ament_package()。

2. 头文件 include

-  #include <ros/ros.h>
-  #include <sensor_msgs/PointCloud2.h>
+  #include <rclcpp/rclcpp.hpp>
+  #include <sensor_msgs/msg/point_cloud2.hpp>

3. 节点初始化

-  ros::init(argc, argv, "mockamap");
-  ros::NodeHandle nh;
+  rclcpp::init(argc, argv);
+  auto nh = std::make_shared<rclcpp::Node>("mockamap");

4. 发布者与订阅者

-  ros::Publisher pcl_pub = nh.advertise<sensor_msgs::PointCloud2>("mock_map", 1);
+  auto pcl_pub = nh->create_publisher<sensor_msgs::msg::PointCloud2>("mock_map", 1);

-  ros::Subscriber sub = n.subscribe("odom", 10, odom_callback);
+  auto sub = g_node->create_subscription<nav_msgs::msg::Odometry>("odom", 10, odom_callback);

回调签名里的 ConstPtr 改为 ConstSharedPtr，消息类型中间加 ::msg::。

5. 参数读取

-  nh_private.param("seed", seed, 4546);
+  seed = nh->declare_parameter<int>("seed", 4546);

参数名里的斜杠改成点号，例如 map/x_size 改成 map.x_size。

6. 时间与日志

-  ros::Time::now()
+  g_node->get_clock()->now()

-  t.toSec()
+  t.seconds()

-  ROS_INFO("...")
+  RCLCPP_INFO(rclcpp::get_logger("mockamap"), "...")

7. 自定义消息（.msg 文件）

类型名中间加 ::msg:: 命名空间，例如 nav_msgs::Odometry 改为 nav_msgs::msg::Odometry；.msg 文件里写 Header header 会报错，要写全 std_msgs/Header header。

三、遇到的错误及解决方法

1. 见notebook.md

2.解决：自己改正之后看报错在哪里，不行的话用ai检错，写入notebook.md方便复习

四、编译与运行命令

编译：先 source instaall/setup.bash，然后执行 colcon build

运行：先 source install/setup.bash，再用 ros2 run 包名 可执行文件名 启动，例如 ros2 run mockamap mockamap_node、ros2 run waypoint_generator waypoint_generator、ros2 run ego_planner ego_planner_node。
