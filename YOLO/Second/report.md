# 训练报告：YOLOv8 目标检测（红球 / 蓝球 / 白框）

## 1. 任务概述

使用 YOLOv8s 训练 3 类别目标检测器，识别红色球（red）、蓝色球（blue）和白色框（blacket），用于机器人视觉抓取。

## 2. 数据集

| 类别 | 含义 | 训练集实例数 |
|------|------|:---:|
| red | 红色球 | 109 |
| blue | 蓝色球 | 100 |
| blacket | 白色框 | 67 |

| 数据集划分 | 图片数量 |
|-----------|:---:|
| train | 103 |
| val | 17 |
| test | 15 |

标注格式为 YOLO 格式（txt）。

## 3. 训练参数

| 参数 | 值 | 理由 |
|------|-----|------|
| 模型 | yolov8s.pt | 平衡速度与精度 |
| epochs | 80 | 约 30 epoch 已收敛 |
| imgsz | 640 | YOLOv8 标准尺寸 |
| batch | 16 | 适配本地 GPU |
| lr0 / lrf | 0.01 / 0.01 | 默认值 |
| mosaic | 1.0 | 小数据集增强 |
| dropout | 0.15 | 减轻过拟合 |
| erasing | 0.1 | 降低增强强度（默认 0.4 对小数据集过强） |
| seed | 0 | 固定可复现 |

## 4. 训练结果

### 4.1 整体指标（Epoch 80）

| 指标 | 值 |
|------|------|
| Precision | 0.993 |
| Recall | 0.831 |
| **mAP50** | **0.855** |
| mAP50-95 | 0.689 |

### 4.2 混淆矩阵分析（各类别检出率）

| 类别 | 正确检出 | 漏检（背景） | 误分类 |
|:---|:---:|:---:|:---:|
| red | **88%** | 7% | 5% |
| blue | **89%** | 8% | 3% |
| **blacket** | **63%** | 35% | 2% |

**blacket 检出率仅 63%，是模型最大短板。** 原因：训练实例仅 67 个（red 的 61%），且白色框视觉特征不如彩色球体醒目。

### 4.3 Loss 分析

- cls_loss 下降 89%，分类能力强
- box_loss 训练/验证差距 0.34，存在一定过拟合（数据量少导致）
- Precision=0.993 极高但 Recall=0.831，模型偏保守

## 5. 遇到的困难与解决过程

### 困难 1：matplotlib 与 numpy 版本不兼容

**现象：** 运行训练脚本一直报错，提示 numpy 版本不匹配。环境中 numpy 被升级到 2.x，matplotlib 不兼容。

**解决：** 逐一排查各库对 numpy 的版本依赖，定位到 matplotlib，升级到支持 numpy 2.x 的新版本。

### 困难 2：对 YOLO 训练流程的遗忘

**现象：** 忘记数据集组织方式、data.yaml 写法、train/val/predict 调用方式及输出文件含义。

**解决：** 查阅 ultralytics 文档，复习了 YOLO 格式数据集结构、标注格式和训练流程。

### 困难 3：尝试提升 blacket 检出率的迭代过程

**第一次尝试 — 微调标签 + 调整超参：**

修改标注框使其更贴合目标边缘，同时添加 `dropout=0.15`、`erasing=0.1`。重新训练（run2）后，结果与 run1 完全一致，所有指标逐 epoch 逐值相同。


**第二次尝试 — 关闭确定性训练：**

设置 `deterministic=False`（run3），希望随机性带来不同的优化路径。训练后结果**仍然与之前相同**。

**结论：** 在当前 103 张数据集上，超参调整和标签微调的空间有限。根本瓶颈是 blacket 样本数量不足（67 个），需要补充数据。

## 6. 改进方向

1. **增加 blacket 样本**：从 67 补到 100+，与 red/blue 持平
2. **调整推理置信度阈值**：当前 conf=0.25，可降至 0.15 提高 Recall
3. **标签标注准确性**：blacket的检出率相较球来说较低，除了blacket样本数量的问题，对blacket的标注效果可
          -能不太好，标注不一致会让模型困惑。
